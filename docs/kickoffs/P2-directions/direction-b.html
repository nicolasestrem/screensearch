Paper Ledger

ScreenSearch as a working paper: a light-led reading surface where your screen history sits in a printed table, not a dashboard.

One serif voice for titles and evidence, a sans for the machinery, and one ink-blue accent for links, selection and focus.

Everything is a document: hairline rules, aligned figures, margin notes, and no chrome that could not have been set in type.

What changed when the store schema became a baseline?

Reading 4 sessions, 38 frames

Still writing

The store stopped shipping a migration chain. 03 §4 now carries the complete DDL at schema_version = 14, and a database at any other version refuses to open with a message that names ssv2c-rebuild.1 The old forward-only steps survive in the spec as provenance, which means the baseline is the whole story and there are no populated-database migration tests to keep.2

The same review removed retired-key tolerance from settings: a file with a dead key is rewritten once with that key gone, and the eight Settings categories become the whole settings surface.
